# ColorCET attribution

The `CET-*.csv` files in this directory are selected ColorCET color-map data distributed in the audited `pyqtgraph-0.14.0-py3-none-any.whl`.

- Color-map creator/source: Peter Kovesi, Center for Exploration Targeting; ColorCET project, <https://colorcet.holoviz.org/>.
- Distribution source used here: PyQtGraph 0.14.0, <https://www.pyqtgraph.org/>.
- License for the selected color-map data: Creative Commons Attribution 4.0 International (`CC-BY-4.0`). The complete license text is retained beside this file as `CC-BY license - applies to CET color map data.txt`.
- Modifications: no numerical modification; ten selected CSV tables are extracted byte-for-byte from the audited wheel. Filenames are unchanged.
- Extraction provenance and SHA-256 values: `manifest.json`.

This attribution applies only to the selected ColorCET data files, not to the project's original source code or user data.
